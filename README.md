# Portfolio — Benoît Tessier

Portfolio personnel présentant mon parcours, mes compétences et mes projets en développement Frontend.

## Technologies

* HTML5
* CSS3
* Sass
* JavaScript

## ⚙️ Prérequis

* [Node.js](https://nodejs.org/)
* npm
* Git

## 📥 Installation

Cloner le repository :

```bash
git clone https://github.com/Ben-tess/portfolio.git
cd portfolio
```

Installer les dépendances :

```bash
npm install
```

Les dépendances nécessaires au projet sont installées automatiquement à partir du fichier `package.json`.

## Sass

Le projet utilise **Sass** pour gérer les feuilles de style.

Lancer Sass en mode développement :

```bash
npm run sass
```

Sass surveille les modifications du fichier source et génère automatiquement le fichier CSS.

Pour arrêter le processus :

```text
Ctrl + C
```

## Lancer le projet

Le portfolio est un site statique.

Après avoir lancé Sass, ouvrir `index.html` dans un navigateur.

Pour faciliter le développement, il est recommandé d'utiliser **Live Server** avec VS Code.

## Dépendances

Les dépendances sont définies dans `package.json`.

Pour installer les dépendances du projet :

```bash
npm install
```

Pour installer Sass manuellement si nécessaire :

```bash
npm install --save-dev sass-embedded
```
