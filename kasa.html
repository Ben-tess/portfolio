Kasa

Création d'une application de location immobilière avec React

[Voir le code]
Toucher pour faire défiler

Contexte

Kasa est une application de location immobilière permettant de consulter des logements et leurs informations détaillées. Le projet avait pour objectif de reproduire fidèlement une maquette tout en construisant une application moderne et structurée.

Objectifs

Développer une interface responsive, mettre en place une navigation entre les différentes pages et créer des composants réutilisables afin de rendre l’application maintenable et évolutive.

Stack technique

React, JavaScript, React Router, Sass, HTML et CSS.

Compétences développées

Ce projet m’a permis de renforcer ma maîtrise de React et de développer une approche basée sur les composants réutilisables. J’ai également approfondi la gestion des routes avec React Router, la gestion des états d’interface et l’intégration responsive d’une maquette.

Résultats et impact

L’application permet de naviguer entre les différentes pages de logements et d’afficher leurs informations de manière dynamique. L’interface est responsive et les différents éléments de l’application sont organisés sous forme de composants réutilisables.

Perspectives d'amélioration

Une évolution possible serait de connecter l’application à une véritable API afin de récupérer les logements dynamiquement et de permettre la gestion de nouvelles fonctionnalités, comme la recherche ou le filtrage des annonces.

Technologies utilisées
